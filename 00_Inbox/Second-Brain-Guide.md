# Second Brain ohne Datenmüll – Guide (Rohmaterial)

**Prinzip:** Nicht alles in Obsidian kippen. Je mehr Datenmüll, desto schlechter die KI-Antworten.
Pipeline: Bronze (00_Inbox) → Agent 1 Sammler → Agent 2 Aufräumer (Silber) → Agent 3 Kurator → du entscheidest (rein/raus) → Gold (30_Wissen). Die KI antwortet nur aus 30_Wissen.

**Ordner:** 00_Inbox, 10_Aufbereitet, 20_Review, 30_Wissen, 90_Archiv, _Vorlagen
**Dateien:** _Vorlagen/Wissensnotiz.md, KI-Regeln.md, Prompts/1_Sammler.md, 2_Aufraeumer.md, 3_Kurator.md

**Ablauf:**
1. Rohmaterial (zuerst 5–10 Dateien) in 00_Inbox legen.
2. KI-Regeln.md + Prompt 1 → Notizen in 10_Aufbereitet (status: roh).
3. Prompt 2 → status: bereinigt, Duplikate nach 90_Archiv.
4. Prompt 3 → 20_Review mit _Übersicht.md (status: review).
5. Du setzt entscheidung: rein/raus. Rein → 30_Wissen, raus → 90_Archiv.
Jeden Prompt in einem neuen Chat laufen lassen. Einmal pro Woche reicht (z. B. Freitag 15 Min. Review).

**Properties:** typ (wissen, anleitung, entscheidung, person, projekt), quelle (nie leer), status (roh → bereinigt → review → freigegeben), entscheidung (offen, rein, raus – nur du).

**Stolperfallen:** Vorlagen im Source mode bearbeiten (sonst überschreibt Live Preview {{date}}). Erst mit Test-Vault starten. Vorlage erst nach 2 Wochen anpassen. Nie löschen, immer archivieren.
